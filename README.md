# Siemens Mobility Virtual Experience Program (Forage)

## Project Overview

This repository contains my completed work for the **Siemens Mobility Virtual Experience Program** hosted on **Forage**.

As part of this engineering simulation, I analysed the information and manufacturing data provided within the virtual experience to identify a production bottleneck and develop an engineering recommendation for improving the Aurora Express wheel assembly process.

The deliverables included a technical report and a presentation outlining the proposed manufacturing layout improvement.

---

# Project Objectives

- Analyse the manufacturing scenario provided during the simulation
- Identify the primary production bottleneck
- Develop an engineering recommendation based on the provided information
- Present a practical layout improvement proposal
- Communicate recommendations through professional technical documentation

---

# Project Deliverables

## Bottleneck Analysis & Efficiency Improvement Recommendation

Prepared a technical report based on the manufacturing scenario provided during the Siemens Mobility Virtual Experience.

The report includes:

- Identification of the primary production bottleneck
- Analysis of operational constraints
- Engineering recommendation
- Expected operational impact of the proposed improvement

---

## Wheel Assembly Layout Proposal

Prepared a presentation describing a proposed improvement to the Aurora Express wheel assembly layout.

The presentation includes:

- Analysis of the existing layout
- Bottleneck assessment
- Proposed dedicated lifting cell
- Cost considerations
- Implementation approach
- Expected operational benefits
